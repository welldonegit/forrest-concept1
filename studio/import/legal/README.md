# Документы сайта: исходники импорта

Скрипт `../legal-documents.mjs` собирает из этой папки и из папки `Тексты/` в корне проекта
фикстуру `src/content-fixtures/legalDocuments.json`; дальше — обычный импорт (`import:build`).

| Документ | Украинский текст | Английский текст |
|---|---|---|
| Політика конфіденційності | `Тексты/Політика конфіденційності.docx` (разбирает скрипт) | `polityka.en.md` (перевод) |
| Документ, що засвідчує право власності (користування) земельною ділянкою | `Тексты/Документ, що засвідчує право … .docx` (разбирает скрипт) | `zemlia.en.md` (перевод) |
| Дозвіл на виконання будівельних робіт | `dozvil.uk.md` — расшифровка PDF из контейнера КЕП (`Тексты/Дозвіл_на_будівельні_роботи_03_07_2026.pdf`, PKCS#7) | `dozvil.en.md` (перевод) |
| Витяг з Державного реєстру речових прав | `vytiah.uk.md` — расшифровка снимка экрана (`Тексты/Витяг з реєстру речових прав.docx` содержит только картинку) | `vytiah.en.md` (перевод) |

PDF и снимок экрана скрипт прочитать не может (подписанный контейнер, картинка), поэтому их текст
перенесён в `*.uk.md` дословно, без правок. Подписи-пояснения бланка под полями («(прізвище, ім’я…)»)
стали названиями строк таблицы; пустые поля бланка не перенесены.

Формат `*.md` (подмножество Markdown):

- `## Заголовок` — раздел, `### Заголовок` — подраздел;
- абзацы разделяются пустой строкой; переносы внутри абзаца склеиваются пробелом;
- `- пункт` — маркированный список, `1. пункт` — нумерованный;
- `| a | b |` — строка таблицы; строка `|---|---|` сразу после первой делает её заголовками столбцов;
- `**жирный**` внутри текста.

Структура английского текста обязана совпадать с украинской (те же разделы, абзацы, строки таблиц):
скрипт сверяет и падает при расхождении.
