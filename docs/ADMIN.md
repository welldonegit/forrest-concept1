# Адмінка сайту FORREST — пам'ятка

Адреса: **https://forrest-trinity.sanity.studio** · вхід — обліковий запис Sanity.

Після кнопки **Publish** сайт перебудовується сам, і за кілька хвилин правка з'являється на сайті. Чернетку (без Publish) відвідувачі не бачать.

## Додати місяць «Хід будівництва»

1. Меню **Хід будівництва** → **+** (створити).
2. Заповніть **Дата** (перше число місяця), **Черга**, у групі **Тексти** — назву й текст українською; англійською — за потреби (порожнє поле на сайті замінюється українським текстом).
3. **Фото** — перетягніть файли. Вмикайте «Декоративне фото» лише для фото, яке нічого не показує; інакше заповніть **Опис фото**.
4. Відео з дрона — посилання YouTube.
5. **Publish**. На сайті нові звіти показуються першими; скільки показувати й коли переносити в архів — налаштування блоку «Хід будівництва» на головній сторінці.

## Замінити фото

1. Відкрийте блок або документ → поле фото → **Replace** (або перетягніть новий файл).
2. Завантажуйте **оригінал**, без стиснення: сайт сам робить легкі версії під кожен екран.
3. Точка фокуса (кнопка з олівцем у фото) — що лишається в кадрі на вузьких екранах.
4. Перевірте **Опис фото** — він має описувати нове фото.
5. **Publish**.

**Чи той файл завантажено.** Sanity зберігає файл без змін і з тим самим розміром у пікселях. Якщо фото на сайті здається меншим чи гіршим, найчастіше завантажено інший файл: копію з месенджера чи пошти (вони стискають фото) або однойменний файл з іншої папки. Розмір завантаженого файлу видно в його адресі: меню фото → відкрити файл, у кінці адреси буде, наприклад, `-941x1672.jpg`. Порівняйте з розміром оригіналу на своєму комп'ютері.

## Виправити текст

Знайдіть блок на **Головній сторінці** (назви блоків — як на сайті) → вкладка **Зміст** → група **Тексти** → розділ мови → **Publish**. Кнопки, підписи форми, меню й футер — у **Налаштуваннях сайту**.

## Правка не з'явилася на сайті

1. Чи натиснули **Publish**? Вгорі документа не має бути позначки «Draft» / «Чернетка».
2. Зачекайте 5 хвилин і оновіть сторінку з очищенням кешу (Ctrl+Shift+R, на телефоні — відкрийте в приватній вкладці).
3. Чи не прихований блок (вкладка **Технічне** → «Приховати блок»)?
4. Не допомогло — напишіть розробнику: що змінили і о котрій. Найчастіша причина — помилка збірки (наприклад, у файлі іконки), розробник побачить її в журналі збірки Cloudflare.

## Випадково видалили або зіпсували

Кошика в безкоштовному тарифі немає, але є **історія змін за 3 дні**:

- **Зіпсували текст чи фото** — у документі меню **⋯** → **Review changes / History** → виберіть версію до помилки → **Restore**.
- **Видалили звіт чи формат** — відкрийте його посиланням з історії (або попросіть розробника), → **Restore**. Пізніше ніж за 3 дні — тільки з резервної копії.
- **Головну сторінку, Налаштування сайту й Ціни** видалити неможливо — у них немає такої кнопки.

## Резервна копія

Робіть копію **перед великими правками** (новий блок, масова заміна фото, переклад) і раз на місяць. Команда з кореня проєкту (потрібен вхід у Sanity CLI):

```sh
npm --prefix studio run -s sanity -- dataset export production ~/forrest-backups/production-$(date +%F).tar.gz
```

Зберігайте копії **поза репозиторієм**. Перша копія: `/home/node/forrest-backups/production-2026-11-19-final-import.tar.gz` (одразу після імпорту).
Відновлення (замінює все в датасеті — тільки з розробником):

```sh
npm --prefix studio run -s sanity -- dataset import <файл>.tar.gz production --replace
```

## Вимоги до іконки (SVG)

Іконки контенту: мітки на карті (блок «Локація» → «Іконки міток») і мережі в «Налаштування сайту» → «Контакти».

- Формат **SVG**, полотно квадратне, бажано `viewBox="0 0 24 24"`.
- **Один колір**: сайт перефарбовує іконку в колір тексту, тож відтінки й градієнти зникнуть.
- Лише фігури (контури, кола, прямокутники). Текст, вбудовані картинки, стилі, скрипти й посилання видаляються при збірці.
- Порожнє поле — показується стандартна іконка.

Службові іконки (стрілки, закрити, меню, play тощо), логотип і шрифти в адмінці не змінюються.

## Для розробника: збірка

- Збірка читає опубліковане з публічного датасету `production` без ключів. Фото береться без втрат (`?fm=png` — ті самі пікселі, що в завантаженому оригіналі), далі `astro:assets` робить AVIF; SVG і PDF — як є.
- `CONTENT_SOURCE=fixtures` — збірка з тимчасових фікстур `src/content-fixtures/` (для звірки).

## Для розробника: одне поле з фікстур у Sanity

Повний імпорт (`dataset import --replace`) перезаписує документи цілком, разом із правками зі Studio. Щоб перенести одне нове поле:

`npm --prefix studio run import:build && npm --prefix studio run sanity -- exec import/patch-field.mjs --with-user-token -- siteSettings notFoundPage`

Поле записується, лише якщо в Sanity його ще немає; `--force` — перезаписати, `--dry` — тільки показати.

## Для розробника: локальний запуск — сайт і API

Сайт і API заявок запускаються окремо: дев-сервер Astro не виконує код Worker.

| Що | Команда | Адреса |
|---|---|---|
| Верстка, живе оновлення | `npm run dev` | http://localhost:4321/uk/ — сторінки; `/api/*` тут **немає** |
| Сайт + API, як у Cloudflare | `npm run build`, потім `npm run dev:api` | http://localhost:8787/uk/ — статика і `POST /api/lead` |
| Тести API | `npm run build`, потім `npm run test:api` | піднімає свій Worker на :8791 з окремою тимчасовою базою |

- Перед `npm run dev:api` скопіюйте `.dev.vars.example` у `.dev.vars` (файл поза Git): там тестова пара ключів Turnstile Cloudflare. Справжні токени (бот, CRM) у `.dev.vars` можна вписати для перевірки, але не комітити.
- Локальна база D1 — у `.wrangler/state`, створюється сама: таблиці Worker створює при першому запиті. Подивитись заявки: `npx wrangler d1 execute DB --local --config wrangler.jsonc --command "SELECT id, created_at, form FROM leads"`.
- `npm run test:api` потребує зібраної сторінки 404. Поки її тексти не заповнені в Sanity, збирайте з фікстур: `CONTENT_SOURCE=fixtures npm run build`. Тестам потрібен інтернет: капчу перевіряє сервер Cloudflare (тестові ключі).
- Після зміни `wrangler.jsonc` оновіть типи для редактора: `npx wrangler types worker/worker-configuration.d.ts --config wrangler.jsonc` (файл поза Git).
- Викладка — **тільки** `npm run deploy` (= `npx wrangler deploy --config wrangler.jsonc`). Звичайний `npx wrangler deploy` бере конфіг адаптера Astro без коду Worker і падає з помилкою `run_worker_first`.

## Заявки: налаштування Cloudflare

Що де лежить (докладно — `docs/LEADS.md`):

- **Секрети** — Worker `forrest-trinity-resort` → Settings → Variables and Secrets → тип *Secret*: `TURNSTILE_SECRET_KEY`, `TELEGRAM_BOT_TOKEN`, `CRM_TOKEN`. Після збереження Worker одразу бере нове значення, правки коду не потрібні.
- **Несекретні налаштування** — `vars` у `wrangler.jsonc` (через коміт): `TURNSTILE_SITE_KEY`, `TELEGRAM_CHAT_ID`, `CRM_SOURCE`, `CRM_STAGE_ID`, `CRM_BUILDING_ID`. У панелі їх не задавати: викладка перезапише.
- **База** — D1 `forrest-leads`, ID у `wrangler.jsonc`. Таблиці створює сам Worker.
- Канал без ключів — статус «не налаштований»; заявки, що прийшли до появи ключів, не досилаються.
- Без ключів Turnstile на бойовому домені форма показує помилку і заявок не приймає. Тестові ключі Cloudflare працюють лише на localhost і `*.workers.dev`.
