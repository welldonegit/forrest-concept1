# FORREST — дорожная карта

Рабочий план вёрстки и запуска. Claude Code идёт по этапам сверху вниз и отмечает готовность в этом файле.

## Как вести этот файл

- Задача закрыта: `- [x] текст — 2026-11-18`. Дату ставь всегда.
- Отмечай задачу, только когда выполнен её критерий готовности и ты это проверил. «Написал код» не равно «готово».
- Задачи с пометкой **(человек)** выполняет владелец проекта. Их не отмечай сам: спроси и отметь после подтверждения.
- Не можешь продолжить — запиши причину в раздел «Блокеры» и переходи к следующей задаче, которая от неё не зависит.
- Этап закрывается, когда закрыты все его задачи и пройдена «Проверка этапа».
- В начале каждой сессии прочитай этот файл и продолжай с первой незакрытой задачи. В конце сессии обнови «Статус» и «Журнал».
- Порядок этапов и формулировки задач не меняй. Нужна новая задача — добавь её в конец этапа с пометкой «добавлено».
