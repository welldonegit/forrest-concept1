# Временные данные вместо Sanity

До подключения Sanity (этап 3) контент лежит здесь в той же форме, что придёт из Sanity:
переводимые поля — массивы `sanity-plugin-internationalized-array` (`[{ "_key": "uk", "value": "…" }]`),
фото — объект `image` с `asset._ref` и переводимым `alt`.

- `uk` — тексты из `design-export/index.html` дословно. Исключение: «Перейти до змісту» (ссылка пропуска к содержимому) — в выгрузке нет, текст утверждён человеком при приёмке 4.0.
- `en` — **тестовый перевод** для проверки вёрстки, не утверждён. Заменяется переводами из админки.
- Фото в фикстурах ссылаются на `design-export/assets/photos/` (`asset._ref: "fixture:<файл>"`).

Компоненты не читают эти файлы напрямую — только через `src/lib/content.ts`.
После подключения Sanity папка удаляется, `content.ts` переключается на запросы к Sanity.
